Qommit privacy policy

Qommit is a Chrome extension that versions Qlik Sense apps in GitHub. Last updated: 2026-11-26.

What Qommit collects

Qommit does not collect any data for its publisher. There is no Qommit server, no analytics, no tracking, and no third-party service. Nothing is sold or shared.

What is stored, and where

These settings are stored only in chrome.storage.local in your browser:

  • your GitHub token,
  • your GitHub organization and repository prefix,
  • the list of Qlik Sense servers you configured,
  • for each Qlik Sense app you linked: the repository, the branch, the app id and the last synced commit, and which apps you chose not to link (key unlinked:<app>).

Qommit also keeps short-lived working data (the journal of a running update and the id of the diff window) in chrome.storage.session. Chrome deletes it when the browser closes.

Where data is sent

  • GitHub. The content of your Qlik Sense apps (commits, history, tags) is sent to and read from the GitHub organization you configured, through api.github.com. Downloads of a repository snapshot are redirected by GitHub to codeload.github.com. The token is sent only to GitHub, to authenticate these requests.
  • Your Qlik Sense servers. Qommit reads and updates apps on the servers you configured. Chrome asks you to allow access to each server when you add it.

Qommit contacts no other host.

Removing your data

Removing the extension deletes everything it stored in your browser. You can change the token and the server list in the extension options. Content already committed to GitHub stays in your repositories; manage it there.
